# 高誌鴻博士教學網站（新版）

這是可直接部署的靜態網站，不需要建置工具或伺服器端程式。

## 檔案

- `index.html`：頁面內容與結構
- `styles.css`：響應式視覺樣式
- `script.js`：手機選單與課程學習方向彈窗

## 部署

將此資料夾內的三個網站檔案上傳至任何靜態網站主機的網站根目錄即可，例如 GitHub Pages、Cloudflare Pages、Netlify 或既有主機空間。

## 維護提醒

- 課程、教材、作業與上課安排應以每學期公告為準；目前頁面不宣稱提供教材下載。
- 聯絡信箱目前使用公開參考網站中的校務信箱；部署前請再次確認是否仍要公開。
- 論文、職稱與學生專題等可驗證資料，應在每次更新時由網站擁有者確認。
